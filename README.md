# Early Warning System Framework 
This is a simple web based simulator for the framework for a potential Early warning system that can be used to detect Flooding in Limestone aquifer regions far before flooding actually occurs and issue warnings to residents based on the threat level. The project is currently being done in aid of the completion of our final project for the Bachelors of engineering in construction engineering course at the University of Technology jamaica on the topic Developing a framework for an Early Warning system for Limestone Aquifers Regions prone to Groundwater flooding: A case study of Content Manchester. The framework takes heavy inspiration from a project of a similar nature completed by user 8DUINOide which is a similar flood monitoring system based on river flow but the area was naga city in the Philipines. Features of the site include:

1) Interactive map with clickable areas and markers

2) Including Markers for all the Boreholes located around the Content Aquifer zone taken from the WRA Report 2026 as well as our interviews with the WRA team that would have visited the site prior to the flooding from Huricane Melissa(2025)

3) We also tried to include the Automated Weather Systems located around the area which their data were implemented into the system could improve the accuracy of the data provided

4) Markers will also be set for emergency shelters in the area as well as the weather conditions including temperature, wind flow, pressure etc. for each marker with data currently being sourced from OpenMateo

5) There are Alert levels set for Safe(Green), Watch(Yellow), Alert(Orange), Critical(Red) where residents would recieve warnings based on threat levels.

6) There is also a forecast simulation tracker where you're able to import cvs data from geoglows based on river segment you are looking at and simulate the threat level over the time period provided.

# How to Run?
just click the link provided below all the features are presented in a fashion that should be somewhat familiar if the user has used apps like Google maps or apple maps 
features like the forecast simulation though require the user to download the Cvs data they want to simulate from geoglows themself and import it into the website for use.

# Future Enhancements
The current design is just a show of what is possible for someone with limited knowledge on coding there are multiple areas where the system can be improved upon given more funding and or its placed in the hands of someone with greater expertise. The biggest barrier for the system though for the future is communication between the different channels. For a system like this to function effectively it would require support from agencies like the WRA, The MSJ, The Fire depqrtmartment and office of disaster preparedness, as well the different municipal organisations for the different parishes.
